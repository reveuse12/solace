# Solace Mobile

Native Expo/React Native companion for Solace, targeting Android and iOS from one TypeScript codebase.

## Current slice

- Stella-style onboarding entry screen
- Native Today, Library, Reflect, and Profile tabs
- Mobile bottom navigation
- Responsive Solace visual language and manifesto home composition

## Run locally

```bash
npm install
npx expo start
```

Use Expo Go for the first UI pass. Native authentication, Supabase persistence, audio, notifications, and store builds are the next integration slices.
